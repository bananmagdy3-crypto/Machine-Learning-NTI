## 🎯 About the Program
The NTI Machine Learning track focuses on mastering core concepts of Data Preprocessing, Supervised & Unsupervised Learning algorithms, Model Evaluation, and practical implementation using Python's data science ecosystem.

---

## 🛠️ Technologies & Tools
- **Language:** Python
- **Libraries:** NumPy, Pandas, Matplotlib, Seaborn, Scikit-Learn
- **Environment:** Jupyter Notebooks / Google Colab

- [x] Data Preprocessing & Feature Scaling (MinMaxScaler, StandardScaler)
- [x] Exploratory Data Analysis (EDA)
- [x] Linear Regression & Polynomial Regression
- [x] Optimization Techniques (Gradient Descent, SGD)
- [ ] Classification Algorithms (Logistic Regression, KNN, Decision Trees)
